# Smart Public Transport Solution 🚌

A web-based smart mobility project focused on making public transportation information easier to access and helping commuters plan journeys with greater convenience.

The goal of **Smart Public Transport Solution** is to support a more connected and commuter-friendly public transport experience through a clear, responsive digital interface. The project can be extended with route discovery, stop information, journey planning, and live service updates as the required transit data sources and integrations are added.

## 🎯 Project Objectives

- Make public transport information easier for commuters to find.
- Simplify the process of exploring routes and transit stops.
- Help users plan journeys with clear, accessible information.
- Provide a responsive interface that works across desktop and mobile devices.
- Create a foundation that can be extended with real-time transport data and smart mobility features.

## 🚀 Planned Capabilities

The following are product goals and may depend on future development and data integrations:

- **Route Discovery** – Explore available public transport routes.
- **Stop Information** – Find transit stops and relevant journey details.
- **Journey Planning** – Support commuters in understanding possible journeys.
- **Service Updates** – Integrate arrival times, delays, or service notices when a reliable data source is available.
- **Responsive Experience** – Make the interface accessible on different screen sizes.

> Feature availability depends on the current application implementation. Real-time arrival information requires an external or operator-provided transport data source.

## 📦 Getting Started

### Prerequisites

- Node.js compatible with the configured Vite version
- pnpm

### Installation

Clone the repository:

```bash
git clone https://github.com/MANIVANNANS-tech/smart-public-transeport-solution.git
cd smart-public-transeport-solution
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Create a production build:

```bash
pnpm build
```

Preview the production build:

```bash
pnpm preview
```

Format the code:

```bash
pnpm format
```
